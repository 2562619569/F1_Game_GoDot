# 《项目代号：ModRacer》游戏核心策划案（GDD初稿）

## 一、游戏基本概述（High Concept）

- **游戏类型**：街机竞速 + 单局战术构筑（Arcade Racing / Session-based Roguelite Tuning）
- **目标平台**：PC 端（键鼠 / 手柄）
- **美术风格**：极简 Lowpoly 风格（简约清爽、色块分明、轻量化高帧率）
- **玩家规模**：1~8 人（支持单人匹配 AI、多人在线开黑对战）
- **核心卖点**："赛道寻宝、局间看图改车、攻防道具互博、末局一战定乾坤"。

## 二、单局核心循环流程（Core Game Loop）

整局游戏由 **4 个独立的小回合（Sub-rounds）** 组成，总时长约 15~20 分钟。

```
[开局选车]
   ➔ [第1回合：赛道搜件+冲刺] ➔ [局间：战术改车+看下张图情报]
   ➔ [第2回合：赛道搜件+冲刺] ➔ [局间：战术改车+看下张图情报]
   ➔ [第3回合：赛道搜件+冲刺] ➔ [局间：决战极限改车]
   ➔ [第4回合：终极决战] ➔ [决出全场总冠军]
```

### 1. 回合竞速规则

- **赛制**：单向点对点冲刺赛（Sprint，A点到B点），单回合用时 3~5 分钟。

- **搜集机制**：
  - **主路路线**：安全平稳，随机散落基础/普通改件。
  - **高风险分支/飞车跳台**：路线狭窄、易失误跌落，但必定刷出高稀有度改件/强力战术武器。

- **决胜规则**：
  - 前3回合为积累与博弈期，不直接决定最终胜负。
  - 第4回合（最终局）第一个冲过终点线的玩家，获得整场比赛的总冠军。

### 2. 动态平衡与防滚雪球机制（Catch-up System）

- **前排奖励**：回合结算排名前列者，获得高品质随机改件奖励（装备优势）。
- **倒序发车惩罚（Grid Penalty）**：上一回合名次越高的玩家，下一回合发车位越靠后；后排玩家享有前排发车优势（路线更干净、起步领先）。

## 三、基础载具系统（3款轿车原型）

玩家在比赛开始前从以下 3 款基础轿车底盘中选择一辆，整局不可更换底盘，但可通过零件大幅改变性能倾向：

| 车型原型 | 驱动形式 | 基础性能特征 | 优缺点与战术定位 | 改件槽位配置 |
| --- | --- | --- | --- | --- |
| 狂暴马力型 | 后驱 (RWD) | 极速上限极高、后段加速极强、车身较重 | 优：长直道霸主，撞击抗性好<br>缺：低速易打滑，雨雪泥地操控难度高 | 4个性能槽<br>1个功能槽 (共5槽) |
| 灵巧敏捷型 | 前驱 (FWD) | 转向反应极快、循迹性好、不易失控打滑 | 优：多弯赛道极其稳定，容错率极高<br>缺：极速上限低，直线冲刺较弱 | 4个性能槽<br>1个功能槽 (共5槽) |
| 全能均衡型 | 四驱 (AWD) | 起步抓地强、全地形适应力极好、起步快 | 优：雨雪/砂石泥泞路面表现优异，各属性均衡<br>缺：无明显极端长板 | 3个性能槽<br>2个功能槽 (共5槽) |

## 四、改装与战术战斗系统

### 1. 改件类型与装备规则

- **唯一装配规则**：每辆车拥有 4~6 个改件槽位，同类型改件只能装备 1 个（例如换装新引擎会自动替换旧引擎）。
- **无限背包机制**：比赛中搜集到的所有改件永久保存在背包中，无容量上限，无需合成，局间可随意换装。

### 2. 改件分类与效果库

**性能类改件（被动属性）**：

- **引擎（Engine）**：提供极速提升、加速度提升。
- **轮胎（Tires）**：提供铺装路面抓地力、越野/泥地抗性、雨雪防滑。
- **尾翼/气动（Spoiler/Aero）**：高速下压力（过弯稳定性）或直线减阻（提高冲刺极速）。
- **悬挂/底盘（Chassis）**：提升飞跳落地稳定性、抗撞击质量。

**功能/战术类改件（主动技能，CD + 弹药限制）**：

- **火箭筒（Rocket）**：锁定前方最近车辆发射，造成减速打转。（如：单回合 2 发，CD 20秒）
- **战术隐身（Stealth）**：车身半透明且无法被自动锁定，免疫追踪攻击，持续 5 秒。（单回合 1 次）
- **超级氮气（Nitrous）**：瞬间喷射提供极强推力。（单回合 3 次，CD 15秒）

## 五、地图特性与局间战术整备（UI & Modifiers）

每个小回合结束后，进入 **30~45 秒** 的局间整备界面，玩家需根据情报调整配置：

### 1. 局间界面展示内容

- **本回合结算**：名次、获得的奖励改件。
- **下回合地图预报**：
  - 路线构成：例如【长直道占比 70%】或【连续九曲弯道】。
  - 地形与天气词缀：例如【暴雨倾盆】、【荒漠砂石】、【冰雪极地】。
- **改件装配台**：直观展示当前属性雷达图（极速、加速、抓地、越野能力），点击背包一键替换。

### 2. 经典克制与配车策略示例

- 预报：**砂石荒漠 + 陡坡跳台** ➔ 换装：拉力越野胎 + 强化悬挂（防止落地失速与泥地打滑）。
- 预报：**高速公路直道 + 晴天** ➔ 换装：大马力涡轮引擎 + 低阻尾翼 + 超级氮气（全堆极限极速）。
- 预报：**暴雨湿滑山路** ➔ 换装：深纹雨胎 + 下压力大尾翼 + 火箭筒（利用弯道超车与武器拦截前车）。
