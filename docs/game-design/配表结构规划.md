# ModRacer 初步配表结构规划

依据《ModRacer-核心策划案-GDD初稿》，按 `docs/配表工作流.md` 规范（sheet 名 `表名-变量名`，前三行 类型/注释/字段名，首列 `id`，单元格数组用 `a|b|c`）规划全部配置表。

规划结果：**保留现有 3 张（车型/改件/地图，小幅补列），新增 4 张（全局参数/回合/赛道掉落/排名奖励）**，共 7 张。**已于 2026-08 落地到 `settings/data/ModRacer.xlsx` 并完成导出**（建表脚本：`settings/tools/add_modracer_tables.py`）。

> 2026-08 修订：按新规范**值与字段名仅允许英文，第 2 行中文注释不导出**（sheet 名改为 `Car-car` 等）；**Map 表精简为 `id/name/desc/weather`**（地图名/介绍/天气，原 terrain/路线构成等列移除）；**Car 表按车辆控制模块 `vehicle.gd` 的真实导出参数扩充物理基础参数**（重建脚本：`settings/tools/rebuild_modracer_xlsx_en.py`）。

## 总览

| 表 | Sheet 名 | 变量 | 状态 | 服务的系统 |
| --- | --- | --- | --- | --- |
| 车型 | `Car-car` | `Settings.car` | 已落地（含物理参数） | 开局选车、底盘基础属性 |
| 改件 | `Part-part` | `Settings.part` | 已落地 | 搜集、改装、战术武器 |
| 地图 | `Map-map` | `Settings.map` | 已落地（精简版） | 局间情报预报、地图名/介绍/天气 |
| 全局参数 | `Game-game` | `Settings.game` | 已落地 | 赛制节奏类全局数值 |
| 回合 | `Round-round` | `Settings.round` | 已落地 | 4 小回合赛制、决战规则 |
| 赛道掉落 | `Loot-loot` | `Settings.loot` | 已落地 | 主路/高危分支的搜件掉落 |
| 排名奖励 | `RankReward-rank_reward` | `Settings.rank_reward` | 已落地 | 前排奖励 + 倒序发车 |

## 一、Car-car（3 行）

展示层字段：`id, name, drive(RWD/FWD/AWD), top_speed, accel, handling, weight, perf_slots, func_slots, desc, grip_road, grip_offroad`

物理基础参数（字段名与 `addons/gevp/scripts/vehicle.gd` 的导出变量一一对应，可直接应用到 Vehicle 节点）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `max_torque` | float | 电机最大扭矩 NM（Motor 组） |
| `max_rpm` | float | 电机最大转速（Motor 组） |
| `final_drive` | float | 主减速比（Gearbox 组） |
| `gear_ratios` | array | 各挡齿比，元素个数即挡数（Gearbox 组） |
| `front_torque_split` | float | 前轴扭矩占比：0=RWD，1=FWD，0.5=AWD（Drivetrain 组） |
| `max_steering_angle` | float | 最大转向角（度，Steering 组，应用时 deg_to_rad） |
| `steering_speed` | float | 转向速率（Steering 组） |
| `brake_force_multiplier` | float | 制动力倍率（Throttle and Braking 组） |
| `coefficient_of_drag` | float | 风阻系数（Aerodynamics 组） |
| `frontal_area` | float | 迎风面积 m²（Aerodynamics 组） |
| `front_weight_distribution` | float | 前轴配重 0~1（Suspension 组） |
| `center_of_gravity_height_offset` | float | 重心高度偏移 m（Suspension 组） |
| `inertia_multiplier` | float | 转动惯量倍率（Suspension 组） |

## 二、改件-part（已建 14 行，建议补列）

现有字段已覆盖性能加成（`top_speed, accel, grip_road, grip_offroad, grip_wet, aero, landing, mass`）与战术参数（`cooldown, ammo, duration`）。

`desc` 只给人看，程序无法执行战术效果，补充两列：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `effect` | string | 效果枚举：`none`(性能件) / `slow_spin`(火箭筒减速打转) / `stealth`(隐身免锁定) / `nitro_push`(氮气推力) |
| `power` | float | 效果强度：打转角速度/推力倍率等，性能件填 0 |

id 沿用百位段约定：`101~` 引擎、`201~` 轮胎、`301~` 尾翼气动、`401~` 悬挂底盘、`501~` 战术武器。

## 三、Map-map（4 行，精简版）

字段：`id, name, desc, weather(sunny/storm/sandstorm/snow)`——仅定义地图名、地图介绍、天气状态。路线构成、地形等留给关卡场景本身表达；如后续需要可用 `scene_path`(string) 关联 Godot 场景资源路径。

## 四、全局-game（新增，键值表）

散落的赛制节奏数值统一收敛，避免硬编码：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | int | 序号 |
| `key` | string | 参数名 |
| `value` | float | 参数值 |
| `note` | string | 中文说明 |

首批参数（示例值即 GDD 建议）：

| key | value | note |
| --- | --- | --- |
| `player_max` | 8 | 最大玩家数（含 AI） |
| `intermission_sec` | 40 | 局间整备时长（GDD 30~45s） |
| `round_count` | 4 | 小回合数 |
| `start_countdown` | 3 | 发车倒计时秒 |
| `lock_ahead_range` | 60 | 火箭筒自动锁定前方距离（米） |
| `loot_pick_radius` | 3 | 拾取改件判定半径（米） |

## 五、回合-round（新增，4 行）

驱动"4 小回合、末局定胜负"的流程：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | int | 回合序号 1~4 |
| `name` | string | 回合名（第1回合…终极决战） |
| `is_final` | bool | 是否决战局（首个冲线者=总冠军） |
| `time_limit` | int | 单回合时限（秒，GDD 3~5 分钟） |
| `map_pool` | string | 本回合候选地图 id，`a|b|c` 格式 |

> 注：掉落规则为全局按路线生效（主路/高危分支各一条），不按回合区分，故回合表不设 `loot_id` 引用。

## 六、掉落-loot（新增）

GDD 核心博弈：主路散落基础件，高风险分支必出高稀有度/战术武器：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | int | 规则 id |
| `route` | string | `main`(主路) / `hazard`(高风险分支) |
| `drop_count` | int | 该路线单回合掉落点总数 |
| `rarity_weights` | string | 稀有度抽卡权重，对应 rarity 1~4，如 `60|30|10|0` |
| `category_pool` | string | 可掉类别，如 `engine|tires|aero|chassis|tactical` |
| `guarantee_rarity` | int | 保底稀有度（hazard 填 2~3，main 填 0 表示无保底） |

示例：id=1 主路 `60|30|10|0`；id=2 高危分支 `0|20|50|30` 且 `guarantee_rarity=2`。

## 七、排名奖励-rank_reward（新增，8 行）

防滚雪球双机制落表：前排给高品质改件，但下回合倒序发车。每行一名次：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | int | 本回合名次 1~8 |
| `reward_count` | int | 结算奖励改件数量（前排多） |
| `reward_rarity_min` | int | 奖励改件最低稀有度（第1名=3，中段=2，末位=1） |
| `grid_next` | int | 下回合发车位（第1名发 8 号位，末位发 1 号位） |

## 运行时读取示例

```gdscript
# 第4回合配置
var r := Settings.round.data[4]
print(r.name, r.is_final, r.time_limit)

# 第1名的下一回合待遇
var rr := Settings.rank_reward.data[1]
print("奖励%d件、稀有度≥%d、下回合%d号发车位" % [rr.reward_count, rr.reward_rarity_min, rr.grid_next])
```
