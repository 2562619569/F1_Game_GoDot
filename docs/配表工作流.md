# ModRacer 配表工作流（Excel → Godot）

基于社区工具 [GDExcelExporter](https://github.com/kaluluosi/GDExcelExporter)（`pip install gd_excelexporter`）搭建，导出器选用 **GDS2.0**（生成 GDScript 数据脚本，Godot 4 原生支持，类型即表格列）。

## 目录结构

```
settings/                  # 配表工程（ee init 生成）
├── export.toml            # 导出配置（引擎/导出器/目录）
├── data/                  # ★ Excel 源表（数值唯一真理源头，进 git）
│   └── ModRacer.xlsx      #   车型-car / 改件-part / 地图-map 三张表
├── dist/                  # 导出产物（进 git，游戏直接读这里）
│   ├── settings.gd        #   autoload 入口，已注册到 project.godot
│   └── ModRacer/*.gd      #   每张表一个数据脚本
├── sample/                # 官方示例表（可删）
├── tools/
│   └── make_modracer_xlsx.py  # 首次建表脚本（仅参考，勿重复执行会覆盖表格）
└── verify/                # 配表回归验证场景
```

## 日常改表流程（策划）

1. 用 Excel/WPS 打开 `settings/data/ModRacer.xlsx` 改数值、加行；
2. 在 `settings/` 目录执行 `ee gen-all`（或运行 `settings/gen_all.bat`）；
3. 回到 Godot 直接运行，数据即生效。无需改任何代码。

## 表格书写规范

每个 sheet 是一张表，sheet 名格式 `表名-变量名`（如 `车型-car` → `Settings.car`）。以 `~` 开头的 sheet 会被忽略（如 `~首页`）。

每张表前三行为表头，之后每行一条记录：

| 行 | 内容 | 说明 |
| --- | --- | --- |
| 第1行 | 字段类型 | `int` `float` `string` `bool` `tr_string`(可翻译) `array` `dict` 等 |
| 第2行 | 中文注释 | 仅给人看 |
| 第3行 | 字段名 | **首列必须为 `id`**；`*` 前缀字段不导出 |

注意：
- 单元格内数组用 `a|b|c` 分隔；
- 删除某张表后需手动删掉 `dist/` 下对应的旧导出文件，`settings.gd` 里的引用也要重新生成（删掉 `dist/settings.gd` 再 `ee gen-all`）。

## 现有表结构

### 车型-car（3 行）
`id, name, drive(RWD/FWD/AWD), top_speed, accel, handling, weight, perf_slots, func_slots, desc`

### 改件-part（14 行）
- 基础字段：`id, name, category(engine/tires/aero/chassis/tactical), rarity(1-4)`
- 性能加成（百分比/数值，性能类专用）：`top_speed, accel, grip_road, grip_offroad, grip_wet, aero, landing, mass`
- 战术参数（功能类专用）：`cooldown(秒), ammo(单回合弹药), duration(效果持续秒)`

### 地图-map（4 行）
`id, name, terrain(asphalt/gravel/snow), weather(sunny/storm/sandstorm/snow), straight_ratio, corner_count, jump_count, hazard_branch, desc`

## 游戏内读取方式

`settings/dist/settings.gd` 已注册为 autoload `Settings`（见 `project.godot` 的 `[autoload]` 段）：

```gdscript
var car := Settings.car.data[1]          # 按 id 取车型
print(car.name, car.top_speed)           # 狂暴马力型 320

for id in Settings.part.data:            # 遍历所有改件
    var p = Settings.part.data[id]
    if p.category == "tactical":
        print(p.name, p.cooldown, p.ammo)
```

## 回归验证

改表导出后可运行 `settings/verify/verify_config.tscn` 场景，它会把三张表的抽样数据和总行数写入 `settings/verify/verify_result.txt`，用于快速确认导出链路没断。
