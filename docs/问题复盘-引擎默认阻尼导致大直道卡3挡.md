# 问题复盘：原厂车大直道只能挂到 3 挡（引擎默认阻尼）

- **日期**：2026-08-20
- **症状**：601 原厂车大直道全油门，1→2→3 挡正常，之后转速/车速在 147km/h 附近渐近停滞，永远升不到 4 挡。
- **修复**：2 行项目设置 + 1 行脚本（见文末），回归全绿，直道可升满 6 挡、极速回到配表 320km/h。

## 结论（TL;DR）

**换挡算法无辜。** 根因是 Godot 4.7 引擎默认 `physics/3d/default_linear_damp = 0.1`
（项目从未显式覆盖，`ProjectSettings` 实测解析为 0.1；Godot 旧版默认为 0，GEVP
车辆模型按 0 阻尼设计，自带风阻/滚阻公式）。0.1 s⁻¹ 线性阻尼对 1500kg 车等效
**150 N·s/m 附加阻力**：40m/s 时吃掉约 6000N 驱动力。3 挡的驱动力/风阻/阻尼
平衡点在 147km/h，而 3→4 升挡线在 7125rpm ≈ 168km/h——**物理上永远够不到**。
1/2 挡因短换挡封顶（0.75/0.82 红线）在低速就完成升挡，不受影响，所以症状
精确表现为"只能挂到 3 挡"。

## 排查路径（供日后复用）

真实物理探针（`/tmp` 裸 SceneTree 脚本 + `physics_frame` 驱动，长平地 Road 组
地面 + `CarBuilder.apply` 装配 601）复现卡挡后，逐层对照实验排除：

1. **换挡决策**：直改 `state.linear_velocity` 注入速度 → 立刻一路升满 6 挡 →
   决策链路（牵引力交点升挡表）无问题，问题在"车速上不去"。
2. **力审计**：轮上推力实测稳定 6900N 前向（`force_vector.y` 及轮 basis 换算
   均核实），但车身加速度只相当于 ~550N——**约 6300N 在物理层消失**。
3. **逐项排除**（每项都有开关对照）：车体碰撞盒蹭地（无接触）、稳定性系统、
   风阻公式、轮-车身力矩耦合、胎模型反馈、`_integrate_forces` 回调、物理查询
   （raycast）、接触摩擦（双材质摩擦归零无效）——全部不是。
4. **拟合定位**：不同速度点反推消失力，全部落在 **F ≈ 150 N·s/m × v** 的一条
   直线上（40m/s 吃 6000N、71m/s 吃 11400N）→ 线性粘滞阻尼特征。
   **裸 RigidBody3D 自由滑行衰减拟合 d ≈ 0.1 s⁻¹**，反查
   `ProjectSettings.get_setting("physics/3d/default_linear_damp")` = 0.1 实锤。

### 顺带发现的第二个坑：物理休眠冻结

排查中实锤：**刚体匀速直线滑行（轮上无净推力、无物理接触）时，物理引擎会休眠
整个 collision island，且 `apply_force` 不会唤醒休眠体**——车被冻在当前速度，
一切施力无效（探针中车速纹丝不动，`sleeping` 却显示 false，新增任何刚体才会
唤醒全岛）。修复：`Vehicle.initialize()` 里 `can_sleep = false`（赛车全程活跃，
不存在"停车省电"需求）。

## 修复内容

| 文件 | 改动 |
| --- | --- |
| `project.godot` | `[physics]` 显式 `3d/default_linear_damp=0.0`、`3d/default_angular_damp=0.0` |
| `addons/gevp/scripts/vehicle.gd` | `initialize()` 首行 `can_sleep = false` |

> 注意：角阻尼归零后横摆/翻滚动态会比以前"活"。碰撞旋转、漂移回正手感如有
> 变化属预期物理修正，微调应改 `collision_kick` / `stability_yaw_strength`，
> **不要**恢复引擎阻尼。

## 验证

- 修复前：直道探针 45s 卡 3 挡 147.5km/h 渐近线；
- 修复后：75s 全油门升满 6 挡，301km/h 仍向 ~320km/h 爬升（与 Car 表
  `top_speed: 320` 吻合）；
- 回归：script_check、shift_logic/shift_rev、tire_model、bump、collision、
  wheel_assembly、camera、engine_audio、drift、rattle、skid、env、grid、
